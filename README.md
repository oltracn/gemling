# Gemling - Gemini Conversation Batch Manager

Gemling 是一款专为 Google Gemini (gemini.google.com) 设计的 Chrome 浏览器扩展。它为 Gemini 的对话列表引入了缺失的“批量操作”功能，大幅提升管理大量对话的效率。

## 🚀 主要功能

- **批量选中**：在对话列表项前自动注入复选框，支持跨对话选中。
- **批量移动至笔记本 (Move to Notebook)**：
  - **半自动化流程**：用户勾选多个对话后点击“添加到笔记本”，扩展会自动触发第一个对话的官方“添加到笔记本”菜单。
  - **智能捕获**：当用户在官方对话框中选择目标笔记本并确认后，扩展会拦截该 API 请求，自动获取 `notebookPath` (笔记本 ID) 和认证令牌。
  - **后台执行**：获取信息后，扩展会自动在后台将其余选中的对话依次移动到同一个笔记本，无需用户重复操作。
- **实时进度反馈**：操作栏会实时显示“处理中 X/Y”以及最终的完成/失败统计。
- **原生体验**：深度集成于 Gemini 侧边栏，UI 风格与原版保持一致。

## 🛠 技术原理

- **`content.js`**：核心逻辑层。负责监听侧边栏 DOM 变化（MutationObserver）、注入复选框和底部操作栏。它协调整个批量操作流程：模拟点击触发官方 UI -> 等待 API 捕获 -> 循环调用后端接口。
- **`probe.js`**：网络侦察层。通过 `main world` 注入拦截页面的 `XMLHttpRequest`。其唯一任务是实时监听 `MUAZcd` 接口（官方“移至笔记本”接口），捕获成功后通过 `CustomEvent` 将关键参数（`at` token, `f.req` 模板等）传回 content script。
- **`styles.css`**：样式定义层。通过 CSS 变量和精心设计的布局，确保复选框和操作栏在 Gemini 界面中显得自然、不突兀。

## 📋 安装指南

1. 下载或克隆本仓库到本地。
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`。
3. 开启右上角的“开发者模式 (Developer mode)”。
4. 点击“加载已解压的扩展程序 (Load unpacked)”，选择本项目所在目录。

## 💡 使用说明

1. 刷新 `gemini.google.com` 页面。
2. 在侧边栏勾选多个对话。
3. 点击底部出现的“添加到笔记本”按钮。
4. **关键步骤**：在弹出的 Gemini 官方选择框中，选择你想要移动到的目标笔记本并点击“保存”。
5. 保持页面开启，观察按钮上的进度条，等待所有对话迁移完成。
